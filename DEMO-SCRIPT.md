# GloWoCo Demo Script

## 3-Minute Demo

### Scene 1: Opening

Purpose:
Introduce the tool and the problem it solves.

Presenter narration:
"This is GloWoCo, the Global Workforce Compliance Tool. It is designed to give global, regional, and country teams one place to navigate workforce compliance requirements across regions, countries, and legal entities. The purpose is to combine country guidance, entity visibility, compliance assessment, and acquisition due diligence in one workspace."

On screen:
- Open [index.html](C:\Users\Srikanth.Parthasarat\OneDrive - WiseTech Global Pty Ltd\Documents\New project\index.html)
- Pause on the home page hero
- Open `View Tool Summary`

Key message:
GloWoCo is both a guidance tool and an assessment tool.

### Scene 2: Role-Based Access

Purpose:
Explain how access changes by user role and country scope.

Presenter narration:
"The tool is role-based. Global roles can see the full footprint, while regional and country roles are restricted to the countries and entities they own. This makes the same platform usable by central teams and local teams without exposing irrelevant jurisdictions."

On screen:
- Use the `Role` selector in the left sidebar
- Switch between a global role and a regional or country role
- Point to the `Role Scope` card

Key message:
One tool, different visibility based on ownership.

### Scene 3: Regional Footprint

Purpose:
Show how the footprint is organized.

Presenter narration:
"The home page organizes the footprint by region. From here, teams can understand where the company currently operates, where there are acquisition targets, how many entities exist in each country, and where higher-risk jurisdictions sit."

On screen:
- Point to the compliance dashboard on the right side of the hero
- Scroll to `Regional Footprint`
- Click through a few regions

Key message:
The homepage is the footprint and governance entry point.

### Scene 4: Country Workspace

Purpose:
Explain the main content experience.

Presenter narration:
"Once a country is selected, the workspace shows the country and entity context, then breaks guidance into functional tabs. That includes general legal context, labor code summary, statutory benefits, hiring, termination, visa process, mobility, and performance management."

On screen:
- Select a country
- Select an entity
- Click through a few workspace tabs

Key message:
Country guidance and decision workflows are in one place.

### Scene 5: Compliance Gap Analysis

Purpose:
Show owned-entity compliance assessment.

Presenter narration:
"For current entities, the sidebar opens Compliance Gap Analysis. This page lets country and functional teams assess the entity against core compliance categories, review country-specific requirements, upload proof, add comments, and track overall status."

On screen:
- Click `Open Compliance Gap Analysis`
- Pause on the hero dashboard
- Point to the region-based status board
- Click a compliance category tab

Key message:
Compliance Gap Analysis is for current-state entity compliance review.

### Scene 6: Acquisition Review

Purpose:
Show target-company due diligence.

Presenter narration:
"For acquisition scenarios, the tool has a separate Acquisition Review page. Teams capture target facts first, the tool generates country-specific diligence workstreams, and then reviewers assess evidence, identify red flags, and prepare a diligence recommendation."

On screen:
- Return to home
- Click `Open Acquisition Review`
- Open `Edit Target Profile`
- Save the target profile
- Show the triggered diligence workspace

Key message:
Acquisition Review is target-facts-led due diligence, not static questionnaire review.

### Scene 7: Submission Workflow

Purpose:
Explain how the review output is packaged.

Presenter narration:
"Once the due diligence review is complete, users can save a draft, submit a locked review version, and export a diligence summary. This creates a structured output that can be shared across People, Legal, and M&A stakeholders."

On screen:
- Point to `Save Draft`
- Point to `Submit for Review`
- Point to `Export Diligence Summary`

Key message:
The tool produces review-ready outputs, not just raw data capture.

### Scene 8: Close

Purpose:
End with value proposition.

Presenter narration:
"GloWoCo helps teams move from fragmented local knowledge to a structured compliance and diligence operating model. It improves visibility across the footprint, supports better decisions, and creates a stronger governance layer for workforce compliance."

On screen:
- Return to home page
- Pause on hero and dashboard

Key message:
GloWoCo is a governance layer for global workforce compliance.

  4. Country workspace
  5. Compliance Gap Analysis
  6. Acquisition Review
